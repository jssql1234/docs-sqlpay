This release upgrades the database to version 155, adds BF Leave Forfeit and Attendance Reward posting to wages, and resolves a formatting issue in the CIMB Bulk DuitNow format. (*247*)

<!-- truncate -->

## Database

Database upgraded to version **155**

---

## Features

- Added **Clock In / Out Address** display in **Time Attendance Summary**
- Added support for **Attendance Reward** posting to wages
- Added **BF Leave Forfeit** (#5595)
- Added **Bank of China IGBT** payroll format Version 1.8 (#6391)
- Added GL code configuration for **SOCSO Invalidity (Accrual)** and **SOCSO Non-Employment Injury (Accrual)** in payroll accounting (#6390)

---

## Updates

- Redesigned **Attendance Reward** form
- Revised **TDP_TASummary** to display all dates even when no summary exists for that day
- Renamed `Classification` field to `Employee Status` on **Maintain Employee**
- Reverted **Alliance Bank** SOCSO payment format to the previous format (#6392)

---

## Bug Fixes

- Fixed `Beneficiary Name` field including consecutive spaces in **CIMB Bulk DuitNow** format (#6395)
